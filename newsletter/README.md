# The AI Loadout Weekly — format

Sent weekly (planned provider: Kit; signup on the site is "coming soon").

1. **Intro** (2-3 lines): the week in one sentence.
2. **Top launches** (4-6): name, date, one-line "why it matters", source link. Pulled from `releases` in `/tools.json`.
3. **Loadout of the week**: one category from `tools.json`, top 3 picks with their verdicts.
4. **CTA**: link to the site.

Target length: under 3 minutes to read. File naming: `issue-NNN.md`.
